 # Scoping Review

Includes the following information of an extensive scoping review:

- database raw data (.xlslx file, .bibtex file): raw dataset of Rayyan database
- findings (.xlsx files): findings divided in:
    + final included articles: 40 finally included articles
    + all ethical scales found: all ethical scales found within the review
    + additionally considered articles: additional articles that are theoretically linked but not relevant enough to be included in the review
- R-Code (to generate .xlsx files from Rayyan database, additional output): R-Code to generate .xlsx files and additional outputs:
    + different wordclouds
    + R-Code include self written functions to get correlations between words (phi coefficient) and to generate a bigram network
    + Latent Dirichlet allocation to finds natural groups of items
